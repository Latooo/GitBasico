# Kario Media — Panel administrativo

Maqueta del **panel administrativo de Kario Media** hecha en **HTML y CSS**, como proyecto del módulo de HTML/CSS en Campuslands.

- Elaborado por **Daniel Latorre** y **Rubén Ortiz**.
- Agradecimientos al Ing. Pedro Gómez y a Campuslands.

## Pantallas

| Vista | Archivo |
|---|---|
| Inicio de sesión | `index.html`, `view/login2.html` |
| Panel principal | `view/main.html` |
| Carga | `view/carga.html`, `view/carga2.html` |
| Añadir | `view/añadir.html` |
| Reportes | `view/report.html` |
| Ayuda | `view/ayuda.html` |

Cada vista tiene su hoja de estilos en `css/`.

## Ejecutar

Abre `index.html` en el navegador; no requiere dependencias.

## Stack

`HTML5` · `CSS3`
